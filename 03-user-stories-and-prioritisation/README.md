# User Stories and Prioritisation

Translated proposed Grad Careers portal capabilities into a Jira backlog and prioritised a minimum usable release.

## Deliverables

- Story map covering referral intake, cohort scheduling, attendance and outcomes, and partner reporting
- MoSCoW prioritisation with rationale, dependencies and temporary workarounds
- Jira backlog containing epics, user stories and acceptance criteria

## Release approach

Must-have capabilities support digital referrals, manual cohort allocation, attendance, completion and outcome recording, and partner report generation.

Should-have capabilities include automatic allocation, notifications, reminders, non-completion reasons, follow-up recording and automatic report sharing.
