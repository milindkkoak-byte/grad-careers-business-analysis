# Process Analysis and Requirements

This project examines the participant journey from referral to partner reporting.

## Deliverables

- AS-IS process map
- TO-BE process map
- Gap analysis
- Functional and non-functional requirements

## Purpose

Identify manual activities and information gaps, then define proposed digital capabilities to support scheduling, attendance, outcome recording and partner reporting.

This is a simulated business analysis case study. Proposed improvements have not been implemented or measured.
