# Power BI Reporting

Analysed illustrative Grad Careers program data to examine participant completion, recorded outcomes and partner performance.

## Deliverables

- Power BI dashboard with interactive filtering and drill-through
- PDF dashboard preview
- Written insights and recommended actions
- Excel source dataset

## Key findings

- Of 1,600 enrolled participants, 960 completed their workshops: a 60% completion rate.
- 52% of participants were recorded as having no outcome.
- Partner completion rates ranged from 56.5% to 62.5%.

## Interpretation

“No outcome” does not establish unemployment. Follow-up is needed to confirm participants’ employment or further-study status.

This project uses illustrative data, not actual organisational performance.
